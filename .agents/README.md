# .agents/skills

Repository-scoped skills for coding agents (e.g. Claude Code) working in
this project. Each subdirectory is one skill with a `SKILL.md` describing
when to use it and the exact steps to follow — analogous to a runbook, but
written for an agent to execute.

Add a new skill whenever a task in this repo has a specific, non-obvious
procedure worth encoding once (deployment, security scans, extending the
agent's tools) rather than re-derived from scratch each time.
